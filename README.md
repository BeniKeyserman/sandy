# 🦀 Sandy – Browser Extension Development Framework

Sandy is an open-source framework designed to make building browser extensions easier, faster, and more maintainable.
It provides a structured way to create, manage, and test your extensions — all in one place.

## ✨ Features
-	🧩 Extension Management – Create and organize multiple extension projects.
-	⚡ Quick Start – Get up and running with a new extension in seconds.
-	🔧 Developer Tools – Built-in support for dependencies, configuration, and packaging.

## 🚀 Getting Started

1. Install Sandy

```
# Clone the repo
git clone https://github.com/BeniKeyserman/sandy.git
cd sandy

# Install dependencies
npm install
```

2. Start the Framework
```
npm run dev
```

3. Create Your First Extension
- Open Sandy in your browser.
- Click Create New Extension and follow the prompts.
